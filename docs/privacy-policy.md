# Privacy Policy – Roam and Report

Roam and Report is a mobile application designed to help users explore
footpaths and report issues encountered while walking.

## Information Collected
The application may collect:
- Location data to place reports on the map
- Images and descriptions submitted by users
- Technical information required for app functionality

## How Information Is Used
This information is used to:
- Display reported issues on the map
- Improve awareness of footpath conditions
- Support community reporting of problems

## Account Information
User accounts are created anonymously and linked to a device.
Users cannot create their own account, and admin permissions must be provided by the developer.

## Third-Party Services
The app uses third-party services including:
- Firebase Firestore
- Firebase Authentication
- Supabase Storage
- MapTiler API
